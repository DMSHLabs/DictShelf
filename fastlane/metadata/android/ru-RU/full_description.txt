wuDict — офлайн-словарь для всех ваших словарях: MDict (.mdx/.mdd), StarDict, Lingvo DSL, Babylon BGL, Aard 2 (.slob), Kiwix ZIM (Википедия, Викисловарь) и wudict markdown. Выделите слово в читалке, браузере или любом другом приложении — и мгновенно получите статьи из всех словарей на устройстве.

<h2>РАБОТАЕТ ИЗ ЧИТАЛКИ</h2>
- Выберите wuDict словарём в Moon+ Reader, ReadEra, Librera, FBReader, KnownReader, KOReader
- Если в меню словарей читалки есть ColorDict, GoldenDict, Aard 2, Lingvo, Fora, эти пункты тоже открывают wuDict
- Выделите текст в любом приложении и выберите → <b>wuDict</b> в контекстном меню

<h2>ГДЕ ВЗЯТЬ СЛОВАРИ?</h2>
При первом запуске wuDict howto покажет ссылки к бесплатным словарям со свободными лицензиями (FreeDict, Викисловарь, Википедия), которые устанавливаются одним нажатием: https://legbehindneck.com/wudict

<h2>ВОЗМОЖНОСТИ</h2>
- Форматы: MDict (.mdx/.mdd), StarDict (.ifo/.idx/.dict), Aard 2 (.slob), Lingvo DSL (.dsl), Babylon (.bgl), ZIM (.zim, library.kiwix.org), wudict markdown (.wudict.md) — простой текстовый словарь, который можно написать в любом редакторе
- Мгновенный поиск по всем словарям в четырёх режимах: по началу слова, точный, по шаблону (c?t, *ology) и полнотекстовый
- Автоматическая группировка словарей по языку, издателю, направлению перевода
- Двойное нажатие на любое слово в статье — поиск этого слова
- Размер шрифта: ☰ → <b>+/-</b>
- Лемматизация (словоформы) для 24 языков: ☰ → ⚙️ → <b>Lemmatization</b>; английские словоформы предустановлены
- Полноэкранный режим, в том числе с выводом под вырез камеры: долгое нажатие на значок wudict → <b>Settings</b>
- Просмотр <b>всех заголовков</b> словаря: ☰ → <b>Browse</b>
- Свои CSS-стили и шрифты во встроенном редакторе: ☰ → ⚙️ → <b>Custom Style</b>
- Импорт из файлового менеджера: нажмите на файл .mdx/.dsl/.bgl/.zim/.slob/.zip/.7z → Поделиться → <b>wuDict</b>
- Долгое нажатие на ссылку для скачивания словаря на веб-странице → Поделиться → wuDict — и словарь установлен

Словари доступны для поиска сразу после добавления. В фоне wudict создаёт компактный индекс заголовков, поэтому поиск почти мгновенный даже по сотням словарей. Подготовка автоматическая и не требует настройки; полнотекстовый поиск и индексация медиа ресурсов опциональны и включаются отдельно для каждого словаря — только там, где нужны.

<h2>ПРИВАТНОСТЬ</h2>
- Без рекламы и телеметрии.
- Сетевое разрешение используется только для связи с сервером внутри самого приложения (127.0.0.1:6888)
- Доступ к хранилищу не нужен: словари импортируются через системный выбор файлов в собственное хранилище приложения.
