Проект wuDict2 довольно сильно стал отличаться от wuDict и в плане интерфейса да и индексы тоже уже несовместимы. Поэтому переименовал в DictShelf во избежания путаницы.


Описание
1. Поддержка lsd
2. Поддержка нового формата dictzip - dz2. оригинальный dictzip хранит размер файла в 32 битах, поэтому размер словаря ограничен примерно 2 ГБ. dz2 использует для размера 64 бита, что позволяет работать с большими словарями. Размер блоков остаётся таким же, как в v1.
3. Горячие сочетания клавиш для отображения и скрытия окна DictShelf, для перевода выделенного слова в другой програме.☰
Сочетания клавиш могут быть одинарные типа Ctrl+Shift+B а могут и двойные - например Ctrl+Shift+B,Ctrl+Shift+B

5. Расширенный поиск

Поиск по словам в заголовке
Эти режимы ищут совпадение с отдельным словом внутри заголовка. Если заголовок состоит из нескольких слов (например, work in progress), поиск сработает, если совпадёт хотя бы одно из них.
ab→   Слово начинается с искомого work → найдет work, worked, workshop
→ab   Слово заканчивается искомым work → найдет work, network, homework
ab    Слово содержит искомое в любом месте work → найдет work, network, homework, working
·ab·  Слово точно совпадает worked → найдет только worked
·ab·+ Слово или лемма точно совпадают worked → найдет worked и work

Поиск по всему заголовку
Эти режимы проверяют весь заголовок статьи целиком, а не отдельные слова в нём.
=   Заголовок точно совпадает work in → найдет только work in
=+  Заголовок или лемма точно совпадают worked → найдет worked и work (заголовок и искомая строка должны состоять из одного слова
*?  Поиск по маске: * — любая последовательность символов, ? — ровно один символ *wo?k*  → найдет work, works, network, homework, work in progress

Поиск в тексте статей
Искать в тексте - Этот режим ищет запрос в тексте статей, а не только в заголовках. Если запрос состоит из нескольких слов, сначала ищется фраза: все слова подряд и в заданном порядке. Если фраза не найдена, ищутся все слова запроса в любом порядке, с расстоянием до 10 слов между ними. Если совпадений всё ещё нет, каждое слово запроса может находиться в любом месте статьи. Поиск переходит к следующему варианту, только если предыдущий не дал результатов.

6. При поиске сначала показываются по 5 найденных словарных статей из каждого словаря, потом в фоне ищутся все словарные статьи, соответствующие запросу пользователя. Словарные статьи выводятся блоками по ☰
Кроме того, можно просмотреть заголовки всех словарных статей словаря - кнопка Browse в заголовке
