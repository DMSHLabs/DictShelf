Dictionary links

Tap Add to put a dictionary into wudict. To share dictionaries, send a link to a single dictionary, a whole folder or a list, and the person you send it to chooses what to install.

    How share links work

    Put https://legbehindneck.com/wudict# in front of a link. On an Android phone with wudict, tapping it opens wudict; anywhere else it opens this page.

    One dictionary
    A link to a dictionary file or an archive of one.
    https://legbehindneck.com/wudict#https://download.freedict.org/dictionaries/eng-deu/1.9-fd1/freedict-eng-deu-1.9-fd1.slob
    A folder
    A link to a web folder that lists dictionary files, or to a Nextcloud shared folder. Everything in it is offered, and the person chooses.
    https://legbehindneck.com/wudict#https://example.org/dictionaries/
    A list
    A link to a text file with one file name or link per line.
    https://legbehindneck.com/wudict#https://example.org/dictionaries/list.txt
    Several files
    Several links after #, separated by commas. Use this for files that are not in a shared folder, such as a dictionary and its .mdd on Google Drive.
    https://legbehindneck.com/wudict#https://drive.google.com/file/d/…/view,https://drive.google.com/file/d/…/view
    On legbehindneck.com
    For files on this site, the link after # can start at the path.
    https://legbehindneck.com/wudict#/dict/euskera/

    List files

    Any name will do, as long as it ends in .txt, which is what makes a web server send it as text. One entry per line, as a file name next to the list or as a full link. A line starting with # gives the collection its title. Blank lines are ignored.

    # Basque · Elhuyar
en-eu-Elhuyar.mdx
en-eu-Elhuyar.mdd
es-eu-Elhuyar.mdx
es-eu-Elhuyar.mdd
https://download.freedict.org/dictionaries/eng-spa/2025.11.23/freedict-eng-spa-2025.11.23.slob

    In a folder of dictionaries, ls -1 > list.txt writes one.

    What wudict reads

    MDict (.mdx with its .mdd), StarDict (.ifo, .idx, .dict), Aard2 .slob, Lingvo .dsl, Babylon .bgl, openZIM .zim and wudict markdown (.wudict.md), either as they are or packed in a .zip or .7z.
